# ChatCut 组装清单

## 导入前

1. 确认项目和当前时间线没有被切换到旧项目。
2. 确认所有叠加素材的透明格式是 WebM Alpha、ProRes 4444 或 ChatCut Motion Graphic。
3. 拒绝黑底 H.264 作为透明素材。
4. 确认素材命名包含镜头和用途，例如 `S03-title-alpha.webm`、`S03-transition-alpha.webm`。
5. 对每个素材记录源文件、目标镜头、目标轨道、开始帧、持续帧、位置、大小和 Alpha 要求。

## 推荐轨道

- 主视频轨：人物 A-roll 或主画面。
- B-roll 轨：全屏录屏、产品画面和不透明视频。
- 叠加轨：标题、卡片、数字、Logo、装饰和透明转场。
- 全局轨：顶部进度条，只放一份，覆盖完整时间线。
- 音效轨：Mouse Click、whoosh、pop、impact 等；每个动作音效独立放置。
- BGM 轨：独立音乐，不嵌进视觉素材。

## 组装顺序

1. 先放主人物和已有字幕。
2. 放全屏 B-roll，确认切换时间和画面尺寸。
3. 放人物圆形画中画，先确认人物位置，再决定文字和卡片位置。
4. 放独立标题、数字、卡片和 Logo 动效。
5. 放顶部进度条并检查它是否不透明、足够细、全片连续。
6. 按分镜为相邻镜头添加转场。
7. 最后加入主要切换点音效和 BGM 音量处理。
8. 做人声加强时只选有口播的人物片段，不选 BGM、B-roll 或音效。

## 组装后

- 用 `preview_timeline` 检查轨道、帧范围、间隙和重叠。
- 用 viewer 检查每个镜头首帧、稳定帧、转场中段和末帧。
- 用 `inspect_item` 检查异常素材的尺寸、位置、透明度、音频和播放速度。
- 字幕已存在时不要调用字幕生成；字幕内容要修改时才进入字幕专用流程。
- 只修复发现问题的镜头，不重新覆盖已经确认的内容。
