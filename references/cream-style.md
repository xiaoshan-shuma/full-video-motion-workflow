# 奶油拼贴风

这套风格是 `full-video-motion-workflow` 的第二个可选视觉系统。它强调温暖、轻量和纸张拼贴感，适合中文真人口播、知识讲解和流程说明。它不是固定模板，也不要求复制某一张参考图。

## 色彩与材质

- 背景优先透明；需要底色时使用奶油白 `#F7F0E5`。
- 主文字：深咖啡 `#3B352F`。
- 高亮色：珊瑚橙 `#E58B76`、鼠尾草绿 `#A9B8A0`、柔雾粉 `#D99A9B`、奶油黄 `#E9C875`。
- 单个画面控制在 2–3 个强调色；避免深蓝、纯黑大底、厚重黑盒和强烈霓虹渐变。
- 卡片用奶油白或低饱和色块，14–18px 圆角，细深咖啡描边和轻微纸张阴影。
- 字体使用思源黑体/Source Han Sans SC；中文主标题用常规或中等字重，不默认加粗。

## 构图

- 每个画面只表达一个重点。
- 默认左侧放一个大关键词，中间保留人物口播区域，右侧放 2–3 个小卡片、缩略图或标签。
- 长文案按语义拆成 2–4 个画面；每个画面保留一个大关键词和一条短辅助说明。
- 小字优先拆成两行；数字、产品名和结论可单独做成贴纸。
- 人物脸、嘴、字幕和主要动作属于禁入安全区。

## 动效与转场

1. 标题从侧面轻微滑入，约 0.4–0.6 秒。
2. 第一个卡片从上方落下并轻微回弹，后续卡片从侧面错峰出现。
3. 卡片错开 0.12–0.20 秒，保持连续但克制的手工拼贴感。
4. 时间轴、数字或进度元素从 0% 平滑增长到目标值。
5. 相邻画面用淡出、同向擦拭或卡片滑移连接，避免硬跳切。
6. 结束时保留最后一帧约 0.5 秒，方便接回人物口播。

叠加到人物上的素材必须导出为透明 WebM VP8/VP9 或 ProRes 4444，并在浅色和深色检查底图上验证没有黑底、黑边或异常半透明。

## 推荐语义映射

| 口播语义 | 主要视觉隐喻 |
| --- | --- |
| 主题/结论 | 左侧大标题 + 右侧文件卡片与标签 |
| 工作步骤 | 时间轴卡片 + 两到三个步骤卡片 |
| 结果/完成 | 完成标签、导出文件卡片或数据贴纸 |
| 重点数字 | 大数字贴纸或轻量计数器 |

不要在同一画面同时堆叠浏览器、流程图、大面板和大量装饰图标；奶油风的重点是留白、层次和易读性。
